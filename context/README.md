# Sample context (fictional)

Used for the first constraint map when no work tracker or CRM is connected. The company, people and items are invented. Every output built on these files must be labelled "sample data".

- `work-items.csv`: 36 open items of a fictional "feature request to shipped" stream with the step each item is in and the date it entered that step. Reference date: 2026-10-19.
- `handoffs.md`: waiting signals pulled from a fictional team channel.
- `meeting-load.md`: meeting hours of the two people at the Decide step.
